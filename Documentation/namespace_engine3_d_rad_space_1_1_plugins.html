◆ ObjectCustomWindow

typedef void *(* Engine3DRadSpace::Plugins::ObjectCustomWindow) (void *hwnd, void *hInstance, void *reflectionData, void *contentManager, void *object)

The function signature for the function that creates a custom window for editing a custom object in the editor.

Returns a pointer to the new or updated object.

The arguments are:

  • HWND : Window Handle
  • HINSTANCE : Instance Handle
  • Engine3DRadSpace::Reflection::ReflectedObject* : Reflection data for the object
  • Engine3DRadSpace::Content::ContentManager* : Content manager for the object
  • Engine3DRadSpace::Objects::IObject* : The object being edited, can be nullptr if the object is being created for the first time

An analogue for the default implementation would be EditObjectDialog(...).ShowDialog().

◆ PluginMain

typedef bool(* Engine3DRadSpace::Plugins::PluginMain) ()

Entry base function for a 3DRadSpace plugin.

Returns
True if succeded.

When called, PluginMain has to:

  • Load resources related to the plugin itself, such as images, windows..., etc. Meaning that it is safe to create windows, display messages boxes here, unline Windows's in DllMain.
  • Define new asset types, if any
  • Optionally find the editor window, and apply modifications and hooks. If failed, return false, then call Logging::SetLastError() to report the failure.
