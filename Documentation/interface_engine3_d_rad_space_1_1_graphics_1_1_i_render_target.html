Detailed Description

Represents an interface for a render target.

A IRenderTarget instance in guaranteed to be a Texture2D, because a render target view requires a texture for read/writing. The interface was separated from the Texture2D/IGPUMultiBuffer inheritance chain to fix a diamond problem issue.
