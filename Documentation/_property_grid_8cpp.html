xPos,

Value:
(DWORD)SendMessage((hwndCtl),LB_ITEMFROMPOINT, \
(WPARAM)0,MAKELPARAM((UINT)(xPos),(UINT)(yPos)))

Gets the zero-based index of the item nearest the specified point in a list box.

Parameters
hwndCtlThe handle of a listbox.
xPosThe x coordinate of a point.
yPosThe y coordinate of a point.
Returns
The return value contains the index of the nearest item in the low-order word. The high-order word is zero if the specified point is in the client area of the list box, or one if it is outside the client area.
