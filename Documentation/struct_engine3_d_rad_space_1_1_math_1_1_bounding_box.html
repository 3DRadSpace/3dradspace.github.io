Detailed Description

Represents a axis aligned bounding box in 3D space defined by position and scale.

This bounding box has the boundaries specified as (Position, Position + Scale). The scale should be positive in all coordinates.

BoundingBox BoundingBox::Transform ( const Matrix4x4 & m) const
noexcept

Returns the smallest axis-aligned BoundingBox that contains this BoundingBox after being transformed by m.

Parameters
mTransformation matrix (translation, rotation and/or scale).
Returns
A new, axis-aligned BoundingBox that fully contains the transformed box.

Unlike transforming Position and Scale directly, this correctly accounts for rotation by re-deriving the axis-aligned extents from the transformed center/half-extents, guaranteeing the result always contains every corner of the original box.
