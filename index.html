3DRadSpace is a free, simple to use, rapid application development game engine. Still in very early development.

Precisely, it is an modernization of 3D Rad v722, with modern features such as plugins, multiple supported RHIs, custom objects, programming directly with C++, or using AngelScript or C# as scripting languages.

The goal of this game engine is simply an more performant and modern implementation of the workflow provided in the older game engine.

Currently, the latest version is 0.1.0Alpha, with NVidia PhysX bindings being the main feature of the release.
