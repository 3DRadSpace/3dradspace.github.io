Changelog

 

3DRadSpace 0.1.0 Alpha

Compared with 0.0.6 Alpha, this release is a complete C++ rewrite with a more stable and usable editor. The backend uses DirectX 11 and the engine is compiled for x64_86.

 

Features and improvements:


  ✓ Revamped the editor, including code-generated object editing interfaces.
  ✓ Added NVidia PhysX 5.5.0 physics objects: GForce, Force, RigidStatic, RigidDynamic, FPCharacter, and Joint.
  ✓ Added primitive geometric objects: Box, Sphere, Cone, and Cylinder.
  ✓ Added shadow mapping with 3x3 PCF.
  ✓ Added basic custom plugin and object support, including C#, AngelScript, and Hello World plugins.
  ✓ Added DDS skybox support and the SpriteBillboard object.
  ✓ Replaced FPVCamera with FreeCam, including six degrees of freedom and an optional arc camera.
  ✓ Added asset management, a working autoupdater, and JSON-based settings and project files.
  ✓ Events now use reflection metadata instead of hardcoded definitions.
  ✓ Replaced 3DRadSpace.Player with a command-line project compiler that generates Visual Studio C++ projects.
  ✓ Added a Visual Studio extension with C++ project and file templates.
 

Removed:


  ✓ Removed XNBConverter, unused 0.0.6 Alpha objects, and 3DRadSpace.Player.
 

Known issues:


  • Memory leak in the EoK demo project.
  • Perspective aliasing on surfaces parallel enough with the light direction.
  • C# scripting is highly unstable; AngelScript and C++ are better supported.
